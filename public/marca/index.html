O botão “Entrar com Atos”

O botão oficial para o login com a Conta Atos no seu site: os arquivos SVG, um HTML e CSS sem script e as regras de uso. Ele serve a quem já integrou o Login Atos (Atos Workspace › Integrações).

Os botões

Três temas, para o fundo do seu site: claro (fundo branco, com borda), escuro (para fundos escuros) e neutro (cinza claro, sem borda). Três tamanhos: grande (56 px de altura), médio (48 px) e pequeno (44 px), todos com área de toque de pelo menos 44 px. Três textos: “Entrar com Atos”, “Continuar com Atos” e “Criar conta com Atos”. E o ícone só, quadrado, para barras estreitas.

“Continuar com Atos” é o texto do “Continuar como”: no Chrome e no Edge, o clique abre a janela do navegador com a Conta Atos aberta nele; nos outros, o mesmo botão leva ao login de sempre.

Os cantos são retos em todos: é a forma da marca da Atos, como o quadrado do “A”. Não há versão arredondada, para o botão ser reconhecido igual em qualquer site.

No HTML, sem script

Um link comum com a folha https://atos.dev.br/marca/botao.css (sem dependência: nem fonte, nem imagem de fora). O texto usa a fonte do sistema (Inter Tight, se o seu site já a tiver); nos SVG, o texto é desenho e não depende de fonte. Sem estilo inline nem script: funciona com uma CSP sem 'unsafe-inline' (o “A” é um SVG no próprio HTML, com as cores em atributos).

As classes: o tema (atos-entrar--claro, --escuro, --neutro), o tamanho (--grande, --medio, --pequeno) e, se quiser, --icone (só o quadrado; o texto continua para leitores de tela) ou --largo (a largura toda). O href é o caminho do seu sistema que começa o login (o que chama comecar() ou entrar()).

Pelo pacote

O @atos.dev.br/entrar (0.4.0) devolve o mesmo HTML. A folha vai junto no pacote, em @atos.dev.br/entrar/botao.css, para quem prefere servi-la do próprio site.

import { botaoEntrarComAtos } from "@atos.dev.br/entrar";

lugar.innerHTML = botaoEntrarComAtos({ tema: "escuro", tamanho: "grande", texto: "continuar", href: "/entrar" });
// tema: "claro" | "escuro" | "neutro"; tamanho: "grande" | "medio" | "pequeno";
// texto: "entrar" | "continuar" | "criar-conta"; icone: true (só o quadrado); largo: true

Regras de uso

Pode

  • Usar os arquivos daqui, o HTML acima ou o helper do pacote, sem pedir licença, para o login com a Conta Atos no seu sistema.
  • Escolher o tema que combina com o fundo, o tamanho e um dos três textos.
  • Pôr o botão ao lado de outros botões de login (Google, e-mail e senha), com o mesmo destaque que eles.
  • Usar a largura toda (--largo) num formulário estreito.

Não pode

  • Mudar a marca: as cores, o “A”, a proporção, o desenho; nem arredondar os cantos, esticar, girar ou pôr sombra e efeito.
  • Trocar o texto por outro que não os três, ou escrever o nome de outro jeito (“ATOS”, “Atos Login”).
  • Usar o botão ou a marca para outra coisa que não o login com a Atos: não para pagamento, não para dizer que o seu sistema é da Atos, parceiro ou recomendado por ela.
  • Pedir a senha da Conta Atos no seu site: o botão leva à Atos (ou à janela do navegador, no “Continuar como”), e só a Atos pede a senha.
  • Diminuir abaixo do pequeno (44 px de altura).

Espaço livre

Deixe em volta do botão um espaço livre de pelo menos um quarto da altura dele (14 px no grande, 12 px no médio, 11 px no pequeno), sem outro texto, ícone ou borda.
